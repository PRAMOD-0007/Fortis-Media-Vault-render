How to use it

  1. Choose Encrypt or Decrypt.
  2. Upload your file and enter a password.
  3. Click the button, then download the result.

Good to know

  • Use at least 8 characters for a password.
  • An auto-generated key can't be recovered, so save it.
  • Encrypted files end in .fmv and need the same password to open.

How it works

Your file is uploaded to the server, where a key is derived from your password using scrypt. The file is then encrypted with AES-256-GCM, which also detects tampering or a wrong password. Everything happens in memory and nothing is stored. Decrypting reverses the process using the same password or key, restoring your original file and name.
